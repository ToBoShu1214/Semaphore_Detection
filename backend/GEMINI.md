# 🚩 旗語辨識教學系統 (Semaphore Recognition & Teaching System) - 開發技術文檔

## 🎯 專案核心願景：教育、量化與輔助修正
本專案致力於解決傳統旗語學習中「動作標準與否難以量化」的痛點。
- **技術轉型**：從早期基於卷積神經網路（CNN）的單純影像分類，轉型為基於**人體關鍵點估計（Pose Estimation）**的幾何角度分析。
- **教育核心**：利用手臂角度的客觀數據，系統能提供「左抬 15°, 右降 10°」這種可量化的教學反饋，實現真正的虛擬教練功能。

---

## 🏗️ 系統技術架構 (Architecture)

### 1. 前後端分離架構
- **後端 (Backend)**: 使用 **Python FastAPI** 框架建立 WebSocket 伺服器，負責高效能的影像運算與邏輯判斷。
- **前端 (Frontend)**: 使用 **React (TypeScript)** 構建實時互動介面，透過 WebSocket 接收運算結果。

### 2. 雙模型協同辨識 (Dual-Model Synergy)
- **姿態模型 (`yolo11s-pose.pt`)**: 執行每一幀的人體姿態追蹤，獲取 17 個關鍵點座標。
- **旗幟模型 (`flag.pt`)**: 
    - **效能控制**: 採動態偵測機制（Seeking 模式下每 5 幀偵測一次），鎖定目標後暫停以釋放資源。
    - **智慧鎖定**: 計算使用者手腕座標與旗幟邊界框（BBox）四角的幾何距離（門檻 150px），並支援單人自動鎖定。

---

## 🤖 偵測引擎核心邏輯 (Detection Engine)

### 1. 狀態機控制流程 (State Machine)
系統透過嚴謹的狀態機管理，確保偵測的穩定性：
1. **`IDLE` (閒則)**：等待目標進入畫面並做出「交叉手勢」啟動或結束。
2. **`WAITING` (準備)**：要求使用者做出雙手垂直放下的預備姿勢。
3. **`READY` (就緒)**：系統待命，使用者可開始比劃信號。
4. **`DETECTING` (穩定偵測)**：確認姿勢穩定度（持續 0.4 秒）。
5. **`GRACE_PERIOD` (判定緩衝)**：執行最終角度計算與手臂伸直判定（具備 1.5 秒延遲機制）。
6. **`COOLDOWN` (冷卻恢復)**：信號採計成功後強制歸位，避免重複輸入。

### 2. 教學校正導引演算法 (核心技術)
實作了一套基於物理直覺的角度引導邏輯，能完美處理跨越身體中線的動作：
- **側別判定**：以 180° 為中線，自動區分「同向側」與「對向側」。
- **動態方向修正**：
    - **同向側 (0°~180°)**：數值增加代表物理高度升高。
    - **對向側 (180°~360°)**：邏輯翻轉，數值減少（靠近頂點 180°）代表物理高度升高。
- **方位導引**：若手部擺放側別錯誤，自動提示「往對面擺」或「擺回原側」。

## 🛠️ 功能模組詳解 (Feature Modules)

### 1. 多模式練習系統
- **自由練習模式**: 即時辨識使用者輸入的 4 位數序列，並根據映射表轉譯為中文字元。
- **指定練習模式**: 針對特定字串挑戰，具備嚴格的錯誤鎖定與「取消」手勢。
- **教學練習模式**: **專案核心**。不執行錯誤鎖定，改以量化角度即時引導使用者達到標準。

### 2. 多層級視聽回饋
- **視覺引導**: 目標字元與對應信號序列同步黃色高亮顯示。
- **音效系統**: 實作 `correct` (信號成功)、`ok` (字元完成)、`success` (練習圓滿) 與 `incorrect` (輸入錯誤) 四種回饋。
- **成果展示**: 結束時彈出帶有淡入淡出 (Fade-out) 動畫的放大成果視窗。

## 🚀 執行與環境配置 (Deployment)

### 一、Python 後端配置 (建議使用 Conda)
本系統具備**動態硬體偵測機制**，啟動時會自動檢查 `torch.cuda.is_available()`：
- **GPU 模式**: 若偵測到 NVIDIA GPU，將自動啟用並開啟 **FP16 (Half-precision)** 運算，極大化推論 FPS。
- **CPU 模式**: 若無顯卡，系統將自動退回 CPU 運行，確保在一般筆電上也能正常運作。

#### 安裝步驟 (解決路徑空格問題):
```bash
conda create -n semaphore python=3.11 -y
conda activate semaphore

# 1. 安裝高效能運算庫 (以 CUDA 12.4 為例)
python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

# 2. 安裝核心依賴項 (包含追蹤所需的 lapx)
python -m pip install fastapi uvicorn websockets numpy opencv-python ultralytics Pillow python-multipart lapx
```

### 二、React 前端配置
```bash
cd frontend
npm install
npm start
```
